# ShotX macOS 截屏录屏软件 PRD

版本：v1.0（MVP）  
状态：评审稿  
日期：2026-08-12  
对应需求：BRA-25

## 1. 文档目的

定义一款在 macOS 上常驻运行、无需登录、以本地处理为默认的轻量截屏录屏工具。产品吸收 Xnip 在截图、标注、长截图和贴图上的高频能力，以及飞书桌面端录屏在区域选择、音视频源组合、快速裁剪和复制分享上的顺畅流程，但不复制飞书的 IM、会议和云协作体系。

## 2. 用户问题

macOS 系统工具可以完成基础截图和录屏，但用户在以下任务中仍需切换多个应用或经历较长路径：

- 截图后立即标注、遮挡敏感信息、滚动拼接或置顶参考；
- 同时录制屏幕、系统声音、麦克风和摄像头；
- 录制后只裁掉首尾，再快速复制或保存；
- 在包含敏感工作内容时，保证素材不被默认上传。

## 3. 产品定位与原则

### 3.1 一句话定位

ShotX 是面向知识工作者和开发者的本地优先 macOS 截屏录屏工具：快捷键唤起，完成后直接复制、保存或贴图。

### 3.2 产品原则

1. **快**：截图从唤起到可复制不超过一个主流程；录屏结束后直接进入轻量裁剪。
2. **简单**：菜单栏常驻，不建设内容管理后台，不强制用户创建项目。
3. **本地优先**：素材、编辑和导出默认只发生在本机；MVP 不提供账号或云上传。
4. **能力按场景出现**：截图展示标注工具，录屏展示音视频源，避免一个全功能编辑器承载所有操作。
5. **安全退出**：权限缺失、磁盘不足或设备断开时给出明确恢复路径，不静默丢失已录内容。

## 4. 目标、非目标与成功标准

### 4.1 MVP 目标

- 覆盖区域、窗口、全屏截图，以及手动滚动长截图；
- 提供截图标注、脱敏、复制、保存和贴图的闭环；
- 覆盖区域或单显示器录屏，并可组合系统声音、麦克风、摄像头和鼠标效果；
- 提供录屏后首尾裁剪、复制和本地保存；
- 首次使用时完成 macOS 权限引导，并允许用户随时查看权限状态。

### 4.2 建议成功指标（Beta 阶段验证）

- 5 名目标用户中至少 4 名无需指导即可完成“区域截图并标注复制”和“带麦克风区域录屏并裁剪保存”；
- 已获权限时，区域选择层在快捷键触发后 300 ms 内可交互；
- 常见 1080p/30fps、30 分钟录屏成功导出率 ≥ 99%；
- Beta 会话无崩溃率 ≥ 99.5%；
- 不发生未获用户确认的网络上传。

指标均为产品目标，不代表当前已有实现或实测结果。

### 4.3 非目标

- 飞书会议录制、会议权限、参会人通知、妙记转写、评论和团队协作；
- 云空间、链接分享、账号体系、跨设备同步；
- 多轨时间线、转场、字幕、滤镜等专业视频编辑；
- 直播、推流、远程控制；
- Windows、iOS、Android；
- 自动识别并遮挡敏感信息。

## 5. 目标用户与核心场景

| 用户 | 核心任务 | 期望结果 |
| --- | --- | --- |
| 产品、设计、运营 | 截取界面并标出修改点 | 一次完成截图、标注和复制 |
| 开发、测试、技术支持 | 记录复现步骤或截取长日志/长页面 | 清晰、可直接分享的图片或视频 |
| 教师、培训者、演示者 | 同时录屏、讲解并展示人像 | 屏幕、声音和摄像头同步输出 |
| 隐私敏感用户 | 截取内部系统并遮挡信息 | 全程本地处理，导出结果不可还原遮挡内容 |

## 6. 竞品调研

调研范围截至 2026-08-12，以官方产品页、官方帮助中心和 Mac App Store 当前公开信息为准；未进行付费版本逐项实机验证。

### 6.1 Xnip 功能清单

| 能力域 | 已确认能力 | 产品启示 |
| --- | --- | --- |
| 截图与选区 | 区域选择；窗口截图可带阴影；按住 Shift 可组合多个窗口；标注中仍可调整截图范围 | 截图选择和裁剪不应被拆成两个重流程 |
| 滚动截图 | 对选定滚动区域持续截取并拼接，旁侧实时预览；适用于文章、代码、聊天记录 | 长截图是系统截图之外的核心差异化能力 |
| 滚动限制 | 动态内容、非纯色背景、滚动过快、非垂直滚动或反向滚动可能令拼接暂停 | 必须给出实时预览、暂停原因和继续/结束入口 |
| 标注 | 官方确认“齐全的标注功能”；可设置默认样式；公开版本记录确认多种箭头样式、本地文件编辑和暗色工具栏 | MVP 只保留高频标注，并记忆最近样式 |
| 贴图 | 将截图或任意图片置顶，浮于其他窗口之上 | 适合比对和临时参考，交互成本低、价值明确 |
| 辅助工具 | 像素取色、像素级选择、物理尺寸单位测量 | 属于专业效率能力，低于截图录屏主链路优先级 |
| OCR | 当前版本支持从截图提取文字 | 可用 macOS Vision 做本地增强，但不阻塞 MVP 首发 |
| 输出与集成 | 自定义文件名、系统分享、用“预览”打开截图 | 输出应遵循 macOS 原生习惯 |
| 隐私 | App Store 描述为完全本地、无网络访问权限 | ShotX 采用同样的本地默认承诺 |

注：Xnip 官方公开页未逐项列出全部标注工具，因此本 PRD 不把第三方文章中的具体标注类型当作 Xnip 已确认事实；ShotX 的标注组合由目标场景独立定义。

### 6.2 飞书桌面端录屏功能清单

本节只调研飞书独立“录屏”能力，不包含飞书会议录制、妙记和直播。

| 能力域 | 已确认能力 | 产品启示 |
| --- | --- | --- |
| 唤起 | 菜单入口；macOS 默认快捷键 `Option + Shift + R` | 录屏必须能在任意应用中快捷键唤起 |
| 选择范围 | 唤起后框选录屏区域；通过特定入口可隐藏飞书自身窗口 | 先选择内容，再展示录制设置，降低干扰 |
| 输出格式 | MP4、GIF | MP4 承载有声长录制，GIF 适合短演示 |
| 鼠标与摄像头 | MP4、GIF 均支持鼠标设置和摄像头 | 演示效果应在录制前可预览 |
| 音频 | MP4 支持扬声器和麦克风；GIF 不支持音频 | 不向 GIF 暴露无效音频配置 |
| 结束与编辑 | 结束录屏后可裁剪录屏时长 | 首发只做首尾裁剪，不建设完整时间线 |
| 输出 | 可选路径下载；可复制到剪贴板并粘贴到其他会话或文档 | “复制”应与“保存”同级，减少分享路径 |
| 限制 | 最长 1 小时；超过 5 GB 发送到飞书会话时转为文件 | 本地产品不需要聊天限制，但要验证长录制和磁盘保护 |

### 6.3 机会结论

| 竞品优势 | 竞品边界 | ShotX 取舍 |
| --- | --- | --- |
| Xnip 截图链路完整、长截图和贴图突出 | 公开定位仍以截图为主 | 保留截图优势，补齐一体化录屏 |
| 飞书录屏从框选到复制分享路径短 | 依附飞书客户端与会话生态 | 复用简短路径，但输出到任意 macOS 应用 |
| 两者都强调快捷入口 | 能力分散在不同应用 | 统一为一个菜单栏入口和两组快捷键 |
| Xnip 强调本地隐私 | 飞书分享依赖其协作体系 | MVP 完全本地，不设登录和上传 |

## 7. MVP 范围与优先级

### 7.1 P0（首发必须）

- 菜单栏常驻与可修改的全局快捷键；
- macOS 权限引导和状态检查；
- 区域、窗口、全屏截图；
- 手动滚动长截图与实时拼接预览；
- 截图标注：箭头、矩形、自由画笔、文字、马赛克、撤销/重做、裁剪；
- 截图复制、保存、系统分享、贴图；
- 区域或单显示器录屏；
- MP4 录制，支持系统声音、麦克风、摄像头叠加和鼠标指针/点击效果；
- 录制倒计时、计时、停止和首尾裁剪；
- 视频复制、保存、在访达中显示；
- 低磁盘空间、权限失效、设备断开和导出失败处理。

### 7.2 P1（首发后）

- GIF 录制与导出；
- 本地 OCR；
- 多窗口组合截图；
- 自动滚动长截图；
- 取色器和物理尺寸单位；
- 截图后用“预览”打开；
- 录屏暂停/继续；
- 摄像头画面位置、尺寸和圆形/圆角样式的更多设置。

### 7.3 暂不投入

- 云分享、AI 摘要、自动字幕、键盘按键可视化；
- 录屏局部放大、复杂鼠标轨迹美化；
- 可重编辑的工程文件；
- 媒体库和标签管理。

## 9. 用户流程

### 9.1 首次启动

1. 用户打开 ShotX，看到简短价值说明和“开始设置”。
2. 产品说明截图/录屏需要“屏幕与系统音频录制”权限；麦克风和摄像头仅在用户启用对应来源时申请。
3. 用户完成授权；若系统要求重启 App，ShotX 保存当前步骤并在重启后继续。
4. 菜单栏显示就绪状态，用户可直接触发截图或录屏。

### 9.2 区域截图

1. 用户按截图快捷键。
2. 全屏出现半透明选择层，用户拖拽区域；边缘提供像素级放大镜和尺寸。
3. 松开后进入就地标注工具栏；选区可继续调整。
4. 用户可标注、撤销、裁剪，然后选择复制、保存、系统分享或贴图。
5. 默认主按钮执行上一次成功动作；Esc 随时无副作用退出。

### 9.3 滚动截图

1. 用户选择“滚动截图”，框选只包含可滚动内容的区域。
2. ShotX 显示“开始”，并提示避免动画、横向偏移和过快滚动。
3. 用户向下滚动；侧边预览实时展示已拼接结果和当前状态。
4. 匹配失败时自动暂停，并说明原因；用户可继续、撤销最后一段或结束。
5. 结束后进入与普通截图相同的标注和输出流程。

### 9.4 区域录屏

1. 用户按录屏快捷键并框选区域；也可切换为整个显示器。
2. 浮动设置条展示输出格式（MVP 为 MP4）、系统声音、麦克风、摄像头和鼠标效果；已启用摄像头时显示预览。
3. 用户点击录制，经过默认 3 秒倒计时后开始。
4. 状态条仅展示时长、声音状态和停止按钮；状态条不进入成片。
5. 用户停止后进入预览，可拖动首尾把手裁剪。
6. 用户复制或选择路径保存；保存完成后可在访达中显示。

## 11. 关键状态与异常

| 状态 | 用户可见反馈 | 可执行动作 |
| --- | --- | --- |
| 未授权 | 菜单栏警示点、缺失权限说明 | 打开系统设置、重新检测、取消 |
| 选择中 | 遮罩、尺寸、放大镜、当前模式 | 确认、重新选择、Esc 取消 |
| 长截图采集中 | 实时预览、已拼接高度、采集状态 | 继续滚动、结束、取消 |
| 长截图暂停 | 明确原因和最后成功位置 | 继续、撤销最后一段、结束 |
| 录屏倒计时 | 大号秒数与取消入口 | 取消 |
| 录屏中 | 时长、启用的音源、磁盘警告 | 停止 |
| 处理中 | 进度和“请勿退出”提示 | 等待；超过阈值后可取消并保留源文件 |
| 未保存结果 | 离开前提醒 | 保存、丢弃、返回 |
| 设备断开 | 非阻塞提示，记录受影响的来源 | 继续其余轨道、停止 |
| 磁盘不足 | 红色警告并安全停止 | 另存到其他卷、删除临时文件 |
| 导出失败 | 原因和临时文件状态 | 重试、另存为、在访达显示临时文件 |

## 13. 非功能要求

### 13.1 兼容性

- MVP 支持 macOS 14 及以上；Apple Silicon 为首要验证平台，Intel Mac 纳入兼容性回归；
- 支持 Retina、多显示器、不同缩放比例和横竖屏混排；
- 使用 macOS 原生屏幕捕获、媒体编码、剪贴板和分享能力，避免新增账号或云依赖。

### 13.2 性能与稳定性

- 1080p/30fps 为首发质量基线；30 分钟录制音画漂移目标小于 200 ms；
- 截图选择和标注过程中交互保持流畅，不因后台编码阻塞鼠标操作；
- 长截图和录屏使用有界缓存，临时数据持续落盘；
- App 异常退出后，下次启动可发现并恢复可用的未完成录屏，不自动删除唯一副本。

### 13.3 隐私与安全

- MVP 不包含登录、上传或远程配置；
- 权限说明必须写明采集内容和用途，拒绝后仍可使用不依赖该权限的能力；
- 临时文件仅存本机应用容器，导出或明确丢弃后按策略清理；
- 摄像头和麦克风启用时始终有可见状态；
- 脱敏标注在导出时与图片合并，不保存可移除标注后显露原文的交付文件；
- 崩溃诊断如未来启用，必须单独征得同意且不得包含截图、录屏帧、文件名或 OCR 内容。

### 13.4 可访问性

- 菜单、设置和编辑工具提供 VoiceOver 标签；
- 关键动作可通过键盘完成；
- 状态不只依赖颜色表达；
- 倒计时和错误提示支持系统减少动态效果设置。

## 14. 数据与分析

MVP 不接入联网分析 SDK。为验证成功指标，内部 Beta 可在用户明确同意后记录不含内容的本地事件计数，例如捕获模式、成功/失败、耗时区间和错误码；用户可查看并导出诊断，也可一键清空。不得记录图像、视频、OCR 文本、窗口标题或文件路径。

## 15. 验收标准

MVP 只有同时满足以下条件才可进入发布候选：

1. 在干净安装环境完成权限授予、拒绝后重试和系统设置返回三条路径；
2. 区域、窗口、全屏截图在 Retina 与双显示器场景下边界和尺寸正确；
3. 用户可完成截图标注、不可逆马赛克、复制、保存、分享和贴图；
4. 静态网页或文档可完成向下滚动拼接；错误滚动会暂停并可保存已成功部分；
5. 区域和单显示器 MP4 录制可分别验证系统声音、麦克风、摄像头和鼠标效果开关；
6. 30 分钟 1080p/30fps 录屏可播放、可裁剪、可复制和另存；
7. 录制时输入设备断开、磁盘空间不足、导出失败均不会静默丢失唯一可恢复素材；
8. ShotX 自身选择层和控制条不进入最终截图/录屏；
9. 所有内容处理默认在本地完成，网络断开不影响 P0 主流程；
10. 目标用户可用性测试达到第 4.2 节门槛，且所有 P0 缺陷已关闭或有明确发布阻断结论。

## 16. 版本路线建议

| 阶段 | 目标 | 范围 |
| --- | --- | --- |
| MVP | 跑通截图与有声录屏两条本地主链路 | 全部 P0 |
| v1.1 | 补齐短演示与文字效率 | GIF、本地 OCR、录屏暂停 |
| v1.2 | 强化专业截图 | 自动滚动、多窗口、取色、物理尺寸 |
| 后续评估 | 依据真实使用数据决定 | 云分享、键盘可视化、智能美化；不预先承诺 |

## 17. 风险与待验证项

| 风险/假设 | 影响 | 验证方式 |
| --- | --- | --- |
| 长截图对动态内容和复杂背景不稳定 | 可能降低核心能力成功率 | 用网页、聊天、代码、表格建立至少 20 个样本的拼接基准 |
| 不同 App 对“复制视频”支持不一致 | 用户可能误以为复制失败 | 验证 Finder、邮件、常见 IM 和文档；不支持时回退为复制文件引用并提示 |
| 系统音频与麦克风混录存在回声或漂移 | 成片质量受损 | 对不同输出设备做 5/30/60 分钟基准测试 |
| 1080p 上限是否满足 Retina 用户 | 过低影响文字清晰度，过高影响体积 | Beta 同时记录用户主动切换质量的需求，不采集内容 |
| macOS 权限重启路径可能造成流失 | 首次任务无法立即完成 | 首次体验可用性测试并记录每一步完成率 |
| 摄像头叠加是否应在录制中移动 | 会增加录制状态和合成复杂度 | MVP 固定位置；只有明确高频反馈再开放实时移动 |

## 18. 研发与 QA 交付边界

建议实现按真实依赖分三阶段推进：

1. **阶段 1：捕获底座**——权限、菜单栏、快捷键、屏幕/窗口枚举、区域选择、文件与剪贴板输出；
2. **阶段 2：并行能力**——截图标注/贴图/长截图，以及 MP4 录制/音视频源/控制状态；
3. **阶段 3：统一收口**——录屏裁剪、异常恢复、多显示器回归、性能与隐私验收。

设计需先交付选择层、截图工具栏、录屏设置条、录制状态条和权限页的关键状态；客户端以本地能力实现，MVP 不创建服务端；QA 依据第 15 节独立建立验收矩阵，并覆盖权限、磁盘、设备断开和多显示器异常路径。
