# ShotX 发布说明（RELEASE NOTES）

> 各版本用户可见变更。版本号规则见 `RELEASE-AND-TEST-POLICY.md`。

## V0.1.17（0.1.17）

- 录屏音频修复：现在可**同时**录制系统声音与麦克风声音。旧实现将两路声音写成 MP4 内两条独立音轨，部分播放器只播一条、且麦克风完全录不上；新实现将两路 PCM 按时间对齐合成单一音轨后编码，从根因上解决「无法同时录制 / 麦克风录不上」。
- 声音与画面同步：混音输出锚定首帧屏幕样本时间戳，系统声与麦克风在同一时间轴上对齐；无麦克风设备或拒绝授权时自动降级为仅系统声，不阻断无麦克风录制。
- 录屏按钮两态/禁用态：扬声器/麦克风/摄像头/鼠标四枚按钮按「开关 + 权限 + 设备」真值表呈现 on/off（断开来源图标带红斜线），切换失败自动回退并提示，不再出现「显示已开启但实际未采集」的假状态。
- 首次录屏默认：全新安装首次录屏时摄像头与麦克风默认关闭，不自动弹出权限请求；仅用户主动开启对应开关时才申请。
- 录制浮动条 `O-REC` 显示来源状态图标、录制时长与停止按钮；录制中 `Esc` 不停止录制。
- 发布前修复（BRA-118 门禁建议）：`beginCountdown` 同时按设备可用性降级来源、VoiceOver 播报与视觉状态保持一致、`stop()` 冲刷音频与回调同队列串行化。

## V0.1.16（0.1.16）

- 修复首次操作时权限申请未真正触发：shotX 现会真实发起 macOS 屏幕录制/系统录音权限申请，并出现在系统设置「录屏与系统录音」权限列表中，可被授权；此前申请被静默抑制、列表看不到 shotX 的问题已解决。
- 权限询问状态仅在系统弹窗真实弹出（授权或拒绝）后记录，申请被抑制时不提前标记，保证之后仍可再次真实申请。
- 首次录屏开启麦克风/摄像头开关时系统弹窗正常出现并注册 shotX 到对应权限列表；拒绝后开关自动关闭并提示。

## V0.1.14（0.1.14）

- 权限申请置顶：全新安装首次启动即发起屏幕录制权限申请，弹窗位于所有 ShotX 蒙层之上、可正常点击授权/拒绝；不再在绘制选区后才申请导致弹窗被蒙层遮挡。
- 首次录屏隐私默认：全新安装首次录屏时摄像头与麦克风默认关闭，不自动弹出权限请求；仅用户主动开启对应开关时才申请权限，拒绝后开关自动关闭并提示。
- 摄像头画中画：开启摄像头开关后立即启动系统摄像头，画面以圆角正方形画中画出现在录制选区左下角（带 margin），支持大/小两档尺寸与镜像、模糊背景（系统支持时）设置；设置态预览与成片中的画中画位置、尺寸、形态一致。

## V0.1.2（0.1.2）

- 修复工具选项的实时样式应用、窄屏工具栏避让与 VoiceOver 公告。
- 完整 Tab/Shift+Tab 键盘焦点链覆盖选区、八个把手、工具栏、工具选项浮层与输出按钮；选区小于 20×20 pt 时隐藏工具栏与尺寸标签，保留把手与键盘调整。
- 极窄工作区（小于 316 pt）下工具选项浮层宽度收敛至可用工作区，不再越界。

## V0.1.1（0.1.1）

- 标注工具栏改为固定元素集；窄屏自动重排为工具/输出两行。
- 样式选项改为独立浮层，支持颜色预设、取色与可拖拽的粗细/字号/马赛克大小，并记忆各工具最近值。

## V0.1（0.1.0）

首个正式版本。

- 菜单栏截屏入口：区域 / 窗口 / 全屏截屏，物理像素输出。
- 标注工具：移动/删除、裁剪、撤销/重做、马赛克、颜色选择器、PNG 复制/保存/分享/置顶。
- 长截图：滚动拼接、暂停/撤销、输出上限保护。
- 本地 MP4 录制：倒计时、状态/停止、磁盘保护、Recovery 保留、播放、头尾裁剪导出、复制/保存/Finder。
- 可编辑全局快捷键（冲突安全）、四类权限校验与刷新。
- 接入 `icon/shotx.png` 作为 APP 图标（打包时自动生成 icns）。
