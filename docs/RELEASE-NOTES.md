# ShotX 发布说明（RELEASE NOTES）

> 各版本用户可见变更。版本号规则见 `RELEASE-AND-TEST-POLICY.md`。

## V0.1.14（0.1.14）

- 权限申请置顶：全新安装首次启动即发起屏幕录制权限申请，弹窗位于所有 ShotX 蒙层之上、可正常点击授权/拒绝；不再在绘制选区后才申请导致弹窗被蒙层遮挡。
- 首次录屏隐私默认：全新安装首次录屏时摄像头与麦克风默认关闭，不自动弹出权限请求；仅用户主动开启对应开关时才申请权限，拒绝后开关自动关闭并提示。
- 摄像头画中画：开启摄像头开关后立即启动系统摄像头，画面以圆角正方形画中画出现在录制选区左下角（带 margin），支持大/小两档尺寸与镜像、模糊背景（系统支持时）设置；设置态预览与成片中的画中画位置、尺寸、形态一致。

## V0.1.2（0.1.2）

- 修复工具选项的实时样式应用、窄屏工具栏避让与 VoiceOver 公告。
- 完整 Tab/Shift+Tab 键盘焦点链覆盖选区、八个把手、工具栏、工具选项浮层与输出按钮；选区小于 20×20 pt 时隐藏工具栏与尺寸标签，保留把手与键盘调整。
- 极窄工作区（小于 316 pt）下工具选项浮层宽度收敛至可用工作区，不再越界。

## V0.1.1（0.1.1）

- 标注工具栏改为固定元素集；窄屏自动重排为工具/输出两行。
- 样式选项改为独立浮层，支持颜色预设、取色与可拖拽的粗细/字号/马赛克大小，并记忆各工具最近值。

## V0.1（0.1.0）

首个正式版本。

- 菜单栏截屏入口：区域 / 窗口 / 全屏截屏，物理像素输出。
- 标注工具：移动/删除、裁剪、撤销/重做、马赛克、颜色选择器、PNG 复制/保存/分享/置顶。
- 长截图：滚动拼接、暂停/撤销、输出上限保护。
- 本地 MP4 录制：倒计时、状态/停止、磁盘保护、Recovery 保留、播放、头尾裁剪导出、复制/保存/Finder。
- 可编辑全局快捷键（冲突安全）、四类权限校验与刷新。
- 接入 `icon/shotx.png` 作为 APP 图标（打包时自动生成 icns）。
