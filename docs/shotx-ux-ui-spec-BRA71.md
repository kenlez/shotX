## 2. 标注对象模型与鼠标命中

### 2.1 对象类型

`O-ANN` 画布上的标注统一视为可命中的对象，全部就地呈现：

| 对象 | 几何 | 命中带 | 样式 |
| --- | --- | --- | --- |
| 矩形 | 以 A、B 为对角的矩形 | 矩形包围盒外扩 4 pt | 颜色、粗细 |
| 椭圆 | 外接椭圆 | 同上 | 颜色、粗细 |
| 直线 | 起终点线段 | 线段距离 ≤ max(粗细/2, 8) pt | 颜色、粗细 |
| 箭头 | 线段 + 箭头 | 线段距离 ≤ max(粗细/2, 8) pt | 颜色、粗细 |
| 画笔路径 | 连续采样点的平滑路径 | 到任一段路径距离 ≤ max(粗细/2, 8) pt | 颜色、粗细 |
| 马赛克矩形 | 以 A、B 为对角的矩形（内部像素化填充） | 矩形包围盒外扩 4 pt | 块大小（无颜色） |
| 文字 | 文本包围盒（随字号/内容自适应） | 包围盒外扩 4 pt | 颜色、字号 |

对象 z 序：后创建者在上；命中时取最上层对象。对象拖动移动、方向键移动、Delete 删除、撤销/重做对所有类型统一生效。

### 2.2 鼠标命中优先级

`O-ANN` 内固定命中顺序（自上而下），与 `shotx-ux-ui-spec.md` §7.1 一致并扩展对象层：

1. 已展开的浮层/菜单：工具选项浮层、取色器（含吸管预览）。
2. 就地标注工具栏本体。
3. 选区八个把手热区（20 × 20 pt）。
4. 画布标注对象（按 z 序，最上层优先）。
5. 选区空白区域内容。

- **选择工具**：命中对象 → 选择；拖动对象 → 移动；命中空白 → 拖动移动整个选区（沿用现有 `Space` 临时移动选区）。
- **绘制工具**（矩形/椭圆/直线/箭头/画笔/马赛克/文字）：命中空白 → 按下即创建新对象；命中已有对象 → 仍创建新对象（绘制工具保持连续绘制，移动交选择工具负责；此为本设计落点，见 §9.1 假设 1）。
- **裁剪**：不生成对象，命中行为沿用现实现。

### 2.3 对象状态

| 状态 | 视觉 | 说明 |
| --- | --- | --- |
| 普通 | 按样式绘制 | 默认态 |
| 选中 | 1 pt `color-accent` 圆角描边包围盒外扩 4 pt | 唯一选中；点击空白取消选择 |
| 创建中 | 按当前样式实时预览（马赛克实时像素化预览） | mouseDown → mouseUp 提交 |
| 编辑中（仅文字） | 就地文本框 + 虚线编辑框，见 §5.3 | Return / Esc / 点击外部提交 |

### 2.4 键盘与历史（FR-BRA71-03 沿用）

- `Delete`：删除当前选中对象（一次一步，进入撤销栈）。
- 方向键：选中对象移动 1 px，`Shift` + 方向键 10 px（与选区/把手口径一致，见 `shotx-ux-ui-spec.md` §7.1）。
- `Cmd+Z` / `Cmd+Shift+Z`：撤销/重做，栈 ≥ 20 步。
- 创建、移动、样式更改、删除、文字内容提交各记一步；文字编辑期间的逐键输入不单独入栈，以提交（Return/失焦）为一个历史步骤。
- `Esc` 优先级（`shotx-ux-ui-spec.md` §14.1 沿用）：关闭浮层/菜单 → 结束文字编辑（保留文字）→ 取消当前未完成绘制 → 丢弃本次截图并退出。

## 3. FR-BRA71-01：马赛克矩形对象

### 3.1 创建交互

马赛克不再接受画笔式连续轨迹；**一次拖拽 = 一个矩形对象**，交互与矩形工具一致：

- 选择"马赛克"后，在选区内按住鼠标设起点，拖动至对边角，松开提交。
- 创建期间按当前块大小对矩形内部做实时像素化预览（从冻结底图取样，同 `shotx-ux-ui-spec.md` 对马赛克"栅格化渲染"的实现口径，仅把"沿轨迹铺块"改为"填充矩形区域"）。
- 两个轴向均 < 4 pt 的拖拽视为无效，不生成对象（mouseUp 丢弃）。
- 对象提交后留在画布，可选中、拖动、Delete、方向键、撤销/重做（同其他对象）。

### 3.2 样式

- 样式区只保留**块大小**（即像素化采样块边长），无颜色。
- 控件标签由"笔刷大小"改为"块大小"（避免与新矩形语义冲突），取值与记忆范围沿用：连续 8–40 px、离散档位 8/16/24/40 px，拖拽条为默认入口（FR-CAP-16 机制不变）。此为文案层面的命名调整，不改取值范围与记忆规则。
- 块大小在创建时读取当前记忆值；创建后更改块大小不影响已创建对象（样式在创建时定格），仅作用于后续新建对象。

### 3.3 渲染与不可逆性

- 渲染：按块大小把矩形内部像素化（每块取对应底图像素均值/代表色），矩形边界外不处理。
- 可逆性：编辑期间对象可移动、删除、撤销——此时并未改写底图；**进入复制/保存/贴图等输出时**，马赛克与底图合并（栅格化），输出物内无法还原遮挡区域（FR-CAP-07 不变，FR-BRA71-01 验收同口径）。

| GT-71-01-2 | 同上 | 用户以曲线轨迹连续拖拽 | 只生成一个由轨迹起点与终点定义的矩形对象；不产生沿轨迹的连续马赛克笔迹 |

## 4. FR-BRA71-02：自由画笔平滑路径

### 4.1 创建交互

画笔绘制一条跟随鼠标真实轨迹的连续平滑路径，不再是起终点直线：

- 按住鼠标起笔，拖动期间**持续采样指针位置**（每次事件至少追加一个点，不做固定距离抽稀；建议按屏幕坐标逐事件采样）。
- 松开提交整条路径为**一个对象**；路径可整体选中、拖动、删除、撤销/重做。
- 总长度 < 2 pt 视为点笔：提交为圆点（round cap，直径 ≈ 粗细值），保证单击不会丢笔迹。
- 创建期间显示实时路径预览，样式（颜色、粗细）取当前记忆值。

### 4.2 平滑规则

- 使用贝塞尔或等效平滑曲线拟合采样点（推荐 Catmull-Rom → 三次贝塞尔，或二次中点平滑）。实现口径：**渲染曲线必须在视觉上经过每个采样点附近且无起终点直线段的"折线感"**。
- 粗细沿整条路径恒定（本次不做压力/粗细渐变，符合 PRD 非目标）。
- 命中测试按 §2.1 的"到路径距离 ≤ max(粗细/2, 8) pt"执行，禁止退化为仅包围盒命中（避免斜穿包围盒空白区域误选）。

### 4.3 Given/When/Then

| ID | Given | When | Then |
| --- | --- | --- | --- |
| GT-71-02-1 | 选"画笔"，颜色红、粗细 3 pt | 按住鼠标沿曲线轨迹移动后松开 | 生成一条跟随轨迹的连续平滑路径对象，曲线在拐点平滑、无折线突变；非仅起终点直线 |
| GT-71-02-2 | 已有一条路径对象，处于选择工具 | 点击路径中部（距路径 ≤ 8 pt） | 路径被选中并高亮 |
| GT-71-02-3 | 路径已选中 | 拖动 | 整条路径移动，形状不变 |
| GT-71-02-4 | 路径已选中 | 按 `Delete` | 路径被删除；`Cmd+Z` 恢复 |
| GT-71-02-5 | 路径已选中 | 点击位于路径包围盒内、但距路径 > 8 pt 的空白处 | 不选中该路径（命中带按到路径距离计算，不按包围盒） |

## 5. FR-BRA71-03/04：对象选择移动与文字就地编辑

### 5.1 对象选择与移动（FR-BRA71-03）

- 所有对象（箭头、矩形、椭圆、直线、画笔、马赛克、文字）创建后**就地留在画布**，不弹出独立结果窗口、不切换视图。
- 选择工具下：单击对象选中（唯一选中，重复点击在其他对象上会转移选中）；点击空白取消选中；拖动选中对象移动。
- 双击规则调整：双击命中文字对象 → 进入就地编辑（§5.3）；双击命中其他对象或空白区 → 沿用快捷复制（CAP-13 双击=复制截图并退出）。命中对象时不触发快捷复制，避免误复制。

### 5.2 键盘与历史

同 §2.4。文字编辑期间键盘事件归输入框处理（`Delete` 删字、方向键移动光标、不作用对象级移动/删除）。

### 5.3 文字就地编辑（FR-BRA71-04）

#### 创建

- 选择"文字"后，在画布上**单击**即在点击点打开就地文本框并进入编辑；**不使用 `NSAlert` 或任何模态输入**。
- 文本框为单行（PRD 非目标：不新增富文本段落样式），随内容自适应宽度。
- 提交（Return / Esc / 点击外部 / 切换到其他工具或开始新标注前先提交当前编辑）。

#### 编辑状态视觉（文本框视觉）

| 元素 | 规格 |
| --- | --- |
| 输入控件 | 无边框、透明背景的文本编辑控件（`NSTextView` 或等效），保证底图可见 |
| 字体/颜色 | 实时取当前文字样式：SF/system 半粗，字号 = 当前字号（11–32 pt），颜色 = 当前文字颜色 |
| 编辑框标识 | 1 pt 虚线 `color-accent` 圆角描边，距文字包围盒内缩 2 pt；仅编辑时显示，提交后消失 |
| 光标 | 系统 accent 色插入符 |
| 提交后视觉 | 转为普通文字对象（按样式绘制）；选中时显示 §2.3 选中描边 |

编辑框属 ShotX 捕获排除层，不进入输出。

#### 样式即时反映

- 编辑中通过工具选项浮层更改颜色/字号 → 输入框内文字**即时**变更为新样式。
- 提交后该文字对象成为普通可选中对象；选中状态下改样式 → 对象实时更新。
- 样式变更（创建时已选则对象已带样式；提交前更改以最终为准）写入该文字工具的最近样式并持久化（FR-CAP-04 记忆规则不变）。

#### 双击重入与空文字

- 选择工具下**双击**文字对象重新进入编辑；内容、颜色、字号保持。
- 提交空文字（清空后 Return / Esc / 失焦）→ 删除该对象（沿用现有"空文字失焦时删除对象"）。
- `Esc` 提交并保留文字、退出编辑（不删除、不丢内容）；再按 `Esc` 进入取消当前绘制/退出捕获链路。

## 6. FR-BRA71-06：录屏设置菜单中心锚定

### 6.1 锚定规则

`O-RSET` 面板默认锚定规则改为**菜单几何中心 = 选区几何中心**。面板视觉与尺寸为 Figma 方案（256 × 140，`#333333` 深色，见 §7.1），本节的锚定/跟随/避让逻辑与面板尺寸无关，尺寸口径取 §7.1：

1. **中心锚定**：面板中心与选区中心对齐（`panel.center = selection.center`），面板完全位于当前显示器可见工作区内（四边各 ≥ 8 pt 边距）。
2. **跟随**：选区每次移动或边/角缩放后，面板**实时重新锚定**到新的选区中心（中心跟随选区中心更新）；原始尺寸 `W × H` 同步刷新。
3. **面板可拖**：用户可手动拖动面板标题/背景到任意位置；下次选区变化时按规则 1/2 重新锚定。
4. **排除成片**：面板属 ShotX 捕获排除窗口；点击"开始录制"后面板隐藏，倒计时/录制阶段不显示，成片不出现设置菜单。

### 6.2 小选区避让规则

中心锚定在两种情形下**不适用**，按避让链处理（优先级自高到低）：

- **避让触发条件（任一满足）**：
  - a) 中心锚定后面板覆盖了选区的**全部四角把手热区**（20 × 20 pt），即用户无法再抓到任一角把手调整选区；
  - b) 中心锚定后面板超出当前显示器可见工作区。
- **避让链**：
  1. 先尝试面板紧贴选区外放置，不覆盖选区：**下方优先**（面板顶 = 选区底 + 8 pt）→ **上方**（面板底 = 选区顶 − 8 pt）→ **左右侧边**（面板靠选区旁，与选区 8 pt 间隔）；水平方向尽量与选区中心对齐。
  2. 避让位仍超出可见区时，面板在可见工作区内贴边，四边 ≥ 8 pt 边距。
  3. 仍放不下时，面板内部设置入口区滚动、底部「开始录制」固定可见（紧凑菜单入口展开为就地浮层，不撑高面板，见 §7.2；`FR-REC-11` 主按钮固定口径不变）。
- 避让位遵循"**不遮挡正在拖动的把手**"：把手拖动开始瞬间若面板命中该把手热区，面板按避让链重定位。
- 仅一个方向小于面板的情形：受限方向走避让链，另一方向保持中心对齐（尽量保证至少一个角把手可用）。

### 6.3 与既有行为的关系

- 交互状态机（`O-SEL → O-RSET → O-COUNT → O-REC`）、`Esc` 返回选区、点击"开始录制"锁定选区、四块纯黑遮罩与边框标识（REC-12）**全部不变**，本变更只调整菜单的默认锚定与跟随。
- 开始录制前的命中优先级（面板 → 把手 → 选区）不变。

## 9. 已覆盖需求与未决风险

### 9.1 已采用的实现级假设

1. **对象移动只由"选择"工具承担**：绘制工具按下即新建对象（即使按下点在已有对象上）。这是"命中后可拖动"（FR-BRA71-03）的落点，与 Xnip/Skitch/macOS 标注惯例一致，且不打断连续绘制。若产品要求"任意工具下命中即拖"请决策（见 §9.2-1）。
2. **文字为单行对象**：`Return` 提交、不换行；多行/段落富文本属 PRD 非目标。
3. **马赛克最小尺寸**：两个轴向 < 4 pt 的拖拽不生成对象。
4. **画笔点笔**：总长 < 2 pt 提交为圆点，避免单击丢笔迹。
5. **块大小命名**：马赛克样式标签由"笔刷大小"改为"块大小"，范围与档位（8–40 px）不变。
6. **对象双击语义**：双击命中文字对象进入编辑；命中其他对象或空白区保持快捷复制。避免误复制。
7. **文字编辑为一个历史步骤**：逐键不入栈，提交（Return/失焦）记一步。
8. **样式创建时定格**：马赛克块大小、文字样式在创建/提交时生效；此后改动只影响新建对象（选中对象改样式仍实时生效，仅马赛克因无颜色且块大小定格而例外）。
9. **录屏菜单布局读法**：三项设置入口在上、分割线、40 pt「开始录制」在下（§7.1）；待确认项见 §7.9-1。
10. **选区边框视觉接管设置态**：设置态（含交互层）与锁定态统一使用 `#07C160` 圆角边框视觉，锁定态隐藏控制点（§7.4）；REC-12 的遮罩/标签/排除行为不变。

### 9.2 待产品/技术确认（未决风险）

1. 任意工具下是否允许"命中已有对象即拖动"（当前设计为仅选择工具可移动）——直接影响绘制工具的连续绘制体验，请产品负责人确认后再进入实现。
2. 双击规则（对象/空白区分流）是否需要保留"双击空白区=快捷复制"；若产品希望双击任意处都复制，文字对象重入编辑需改触发（如长按或工具态双击）。
3. `rectangle.svg` / `circle.svg` 内容重复（均为圆形），是否需按 Figma 源重新导出矩形图标；若暂不重导，矩形/椭圆工具图标在界面上将同形。
4. 马赛克块大小的"定格"口径（创建后改动不影响已创建对象）是否可接受；若希望选中马赛克对象可改块大小并重采样，属范围外新增能力，需另行决策。
5. 画笔平滑算法的具体拟合方式由客户端自选（Catmull-Rom/二次中点等），本文只定验收口径（"视觉上无折线感、经过采样点附近"）；若算法导致性能问题（高采样点长路径），需在实现前与技术对齐采样策略。
6. `FR-BRA71-07` 专项：原始尺寸与倒计时在紧凑菜单中的去向、按钮文字颜色（对比度）、布局读法、圆角/阴影数值、入口状态表达——见 §7.9，实现（BRA-79）前必须逐项落定。
