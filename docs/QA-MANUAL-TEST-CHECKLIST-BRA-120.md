## 2. 手测用例

### 2.1 A1/A2/A3 屏幕录制权限

- **TC-120-S-01（首启屏幕录制权限弹窗真实弹出、置顶可点）**
  - Given：全新安装（或清除 ShotX 屏幕录制权限记录），ShotX 处于未授权状态
  - When：启动 ShotX（首次）
  - Then：**系统**屏幕录制权限弹窗真实出现（非应用自建弹窗），位于所有窗口/蒙层之上、可点击；弹窗出现后 shotX 出现在系统设置 → 隐私与安全性 → 录屏与系统录音 列表中（授权前为「未打开」）
  - 结果：

- **TC-120-S-02（授权后注册为已允许）**
  - Given：TC-120-S-01 弹窗出现
  - When：点击授权「好」/「打开系统设置」并允许
  - Then：系统设置「录屏与系统录音」列表出现 shotX 且状态为「已打开/已允许」；再次启动不再自动弹窗
  - 结果：

- **TC-120-S-03（拒绝/取消后不烧毁 flag，可再次真实申请）**
  - Given：TC-120-S-01 弹窗被拒绝或取消，shotX 未在权限列表中注册
  - When：退出并重新启动 ShotX
  - Then：应再次出现**系统**屏幕录制权限弹窗（而非仅应用自建说明弹窗）——证明 flag 未被提前烧毁、请求未被抑制（对应 R1 验证）
  - 结果：

- **TC-120-S-04（未授权时捕获命令拦截、不静默失败、不建蒙层）**
  - Given：屏幕录制权限未授权（已被拒绝）
  - When：从菜单栏触发截图 / 录屏
  - Then：不出现选区蒙层；出现拦截说明弹窗，含「打开系统设置」「取消」两个按钮；点「打开系统设置」跳转到系统设置对应权限页
  - 结果：

### 2.2 A4 麦克风按需申请

- **TC-120-M-01（开启开关触发系统麦克风弹窗、注册到「麦克风」列表、不被面板遮挡）**
  - Given：首次进入区域录屏设置态（O-RSET），麦克风权限未授予，开关默认关闭
  - When：开启「麦克风」开关
  - Then：此时才发起**系统**麦克风权限弹窗，且不被 O-RSET 设置面板遮挡、可点击（验证 A5）；授权后系统设置 → 隐私与安全性 → 麦克风 列表出现 shotX 且为「已打开」
  - 结果：

- **TC-120-M-02（拒绝后开关自动关闭并提示）**
  - Given：TC-120-M-01 弹窗被拒绝
  - Then：麦克风开关自动回退为关闭；提示「麦克风不可用。你仍可继续无麦克风录制。」；仍可无麦克风开始录制
  - 结果：

- **TC-120-M-03（首次录屏默认不申请、摄像头默认关）**
  - Given：全新安装首次进入 O-RSET
  - When：查看设置面板
  - Then：麦克风、摄像头开关均默认关闭；未开启前不自动弹出麦克风/摄像头权限请求；开启摄像头开关时才申请摄像头权限
  - 结果：
