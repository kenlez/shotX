# BRA-125 PRD：截屏/录屏开始前矩形框与锚点统一为蓝色，录屏中保持红色，录屏按钮改蓝

## 1. 用户问题

当前录屏、截图绘制（选区）的矩形框与锚点以及录屏按钮均为绿色；用户已更新设计文件，要求：

- 截屏、录屏**开始之前**的矩形框与锚点 → 统一为**蓝色**。
- **录屏中**的框 → 保持**红色**。
- 录屏按钮（开始之前的状态）当前为绿色 → 调整为**蓝色**。

## 2. 范围

- 录屏设置态选区边框与锚点（`CaptureCoordinator.drawSetupBorder`）：绿 `#07C160` → 蓝。
- 录屏覆盖层边框（`RecordingRegionBorderView`）：`.setup`/`.countdown`（开始前）绿 → 蓝；`.recording`（录屏中）保持红 `#FA5151`。
- 录屏开始按钮资产 `record-start.svg`：绿 `#07C160` 背景 → 蓝。
- 截图选区（非设置态）已为蓝 `#10AEFF`，无需改动，作为统一蓝色基准。

## 3. 非目标

- 不改动 `ResultWindow.swift` 保存按钮的绿色（非本工单语义）。
- 不改动截图/滚动截图流程逻辑。
- 不新增依赖、不做服务端任务。
- 不引入新设计文件；蓝色值沿用应用既有蓝 `#10AEFF`（如设计文件另有明确色值，以设计标注更新为准）。

## 4. 用户流程

区域截图/录屏 → 框选选区（蓝色框 + 蓝色锚点）→ 录屏设置面板（蓝色「开始录制」按钮）→ 开始录制 → 录屏中红色边框 → 停止。
