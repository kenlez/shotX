### 1.2 最终工具集与建议顺序

结构按 `image.png`/`f0efc2ac` 像素结构实测：深色 pill（实测底色 ≈ `#323232`，圆角），图标分左右两组排列。**组内逐图标身份受位图精度限制，下列顺序为「建议顺序」，须按 Figma 源逐项复核（§9 待确认 1）。**

```
[工具组] 矩形 · 椭圆 · 画笔 · 箭头 · 马赛克 · 文字（· 直线？）
   │ 分割线（§4）
[操作组] 撤销 · 重做
   │ 分割线（§4）
[样式]   样式（固定宽按钮，显示当前色块 + 摘要）
   │ 分割线（§4）
[输出组] 复制 · 保存 · 贴图 · 关闭
```

逐项说明：

- **矩形 / 椭圆 / 画笔 / 箭头 / 马赛克 / 文字**：6 个绘制工具，与 `shotx-ux-ui-spec.md` §7.1、BRA-71 §2.1 的对象模型一致。
- **直线（`line`）**：`shotx-ux-ui-spec.md` 对象模型含「直线」，但当前实现 `AnnotationTool` 无此工具、BRA-71 也未落地。`f0efc2ac` 工具栏位图在矩形、椭圆后出现疑似斜线/直线小图标（像素采样见 §9 待确认 1）。**是否纳入本版工具栏请产品确认**（默认：不纳入，不扩张需求）。
- **长截图**：独立入口，不参与工具样式浮层（无颜色/粗细）。点击行为沿用滚动截图链路（BRA-82 范围第 6 条）。
- **撤销 / 重做**：`undo.svg`（撤销）已存在；**redo 无现成资产**，需按设计图导出或使用 `undo.svg` 镜像，见 §3.3。
- **样式**：固定宽按钮，展示当前工具样式摘要（颜色色块 + 当前值，如「红 · 2 pt」，FR-CAP-15）；选择/裁剪工具下置灰。点击开合工具选项浮层。
- **输出**：复制、保存、贴图、关闭（BRA-71 §9.3 已移除「分享」；`close.svg` 为红色 `#FA5151`，与位图实测红色关闭图标一致）。
- **裁剪**：当前实现第 7 个工具为 `.crop("裁剪")`。设计图位图中未清晰识别独立裁剪图标（`annotation.svg` 内容为「圆内 T」，见 §3.2）。**裁剪工具的保留/图标语义请产品确认**（§9 待确认 2）。

### 1.3 工具行为约束（沿用 BRA-71，未变化）

- 绘制工具在空白按下即新建对象；命中已有对象仍新建（连续绘制），移动由选择语义承担（BRA-71 §9.2-1 未决项见 §9 待确认 3）。
- 对象选择/移动/删除/撤销：`O-ANN` 内所有对象（矩形、椭圆、画笔、箭头、马赛克、文字）创建后就地留在画布，可选中、拖动、Delete、方向键微调、撤销/重做（BRA82-02、BRA82-03）。命中带与 z 序见 §6。

## 3. 分割线（图标分割线）

用户请求 #5 要求「按设计图完完整整、原模原样」实现。像素结构实测：工具栏内图标按「工具组 → 操作组 → 样式 → 输出组」分组，**组间存在明显空隙**，但分割线本体（独立竖线）在 `image.png` 采样中未能与图标抗锯齿噪声分离出稳定数值。

| 项 | 结论 |
| --- | --- |
| 是否必需 | 是（用户请求 #5，验收 BRA82-03）。 |
| 位置 | 工具组与撤销/重做之间、撤销/重做与样式之间、样式与输出组之间；位于工具栏 pill 高度中部。 |

## 4. 工具样式浮层与 drop_over_normal（色卡）

### 4.1 概念定位

`drop_over_normal` 是设计图（Figma）中「工具样式下拉浮层」在 normal 状态下的样式命名。即：点击带选项工具后，在工具栏下方展开的样式面板（对应 `shotx-ux-ui-spec.md` §7.3 工具选项浮层，FR-CAP-15）。

### 4.2 现有规范基线（可复用）

- 浮层固定宽 300 pt，锚定工具栏下方 6 pt，避让下 → 上 → 贴边（FR-CAP-15）。
- 内容：记忆值回显行 + 颜色区 + 尺寸区。
- 颜色区：12 个预设色块（2 行 × 6）+「取色器」按钮；色块选中态用 accent 描边 + 对勾（不只靠颜色）。
- 尺寸区：可拖拽笔刷/字号组件 + 离散档位快捷按钮 + 当前值回显（FR-CAP-16）。
- 各工具独立记忆最近样式（FR-CAP-04）。

### 4.3 位图核对结果与待确认

三张位图中**均未展开**工具样式浮层（未捕获到 12 色块面板），仅工具栏内采样到两处色元素：蓝色区域（约 `#0B86F3`，`image.png` x≈1080–1140）与红色关闭图标（`#DB1F0D` 系，x≈1794–1862）。因此：

- **`drop_over_normal` 色卡的本体（色序、色值、块尺寸、选中态）待确认**（§9 待确认 6）：请按 Figma 源读出 12 色清单与高亮/对勾样式后回填本表。
- 机制与交互沿用 §4.2 基线，本任务只替换视觉。

### 4.4 文字工具差异（用户请求 #7 明确要求）

用户明确「字体工具的 drop_over 样式是不一样的」。差异面**具体数值待确认**（§9 待确认 7），至少应覆盖以下维度，实现前必须落定：

### 7.2 贴图（pin）坐标约束（用户请求 #9、BRA82-06）

| 约束 | 规则 |
| --- | --- |
| 坐标系 | 贴图窗口位置/尺寸必须使用**目标显示器本地坐标**（相对该 display frame 的 point 值）并乘 `backingScaleFactor` 换算到物理像素；禁止反复用全局坐标↔本地坐标往返映射导致累积漂移（跳帧根因）。 |

| Retina/异构缩放 | 按各自屏幕坐标/像素比例映射（PRD 边界节）。 |

## 8. 滚动自动捕获 UX 状态（BRA82-05）

自动滚动不再手动逐段采集：指针在已选矩形区域内真实滚动 → 节流采样 → 重叠拼接 → 实时预览。不得模拟滚轮、控制第三方窗口、新增依赖（PRD 边界节）。

| 状态 | 触发 | 视觉/反馈 | 可执行动作 |
| --- | --- | --- | --- |
| 就绪 | 进入滚动截图，预览为空 | 预览板显示提示（沿用现有滚动链路文案） | 开始滚动 |
| 采集中 | 指针在选区内滚动，检测到连续重叠 | 预览板实时更新（成功拼接后 500 ms 内刷新） | 继续滚动 / 完成 / 撤销 |
| 暂停-无连续内容 | 连续两帧无可靠重叠 | 横幅「已暂停：无法找到连续内容」（沿用旧规范 `LONG-paused-match`） | 继续 / 撤销最后一段 / 结束 |
| 暂停-滚动过快 | 滚动过快 | 「已暂停：滚动过快，请慢一些」 | 同上 |
| 暂停-横向偏移 | 横向偏移 > 8 px | 「已暂停：检测到横向移动」 | 同上 |
| 上限 | 高度/内存达上限 | 「已达上限」横幅，停止追加 | 结束 / 撤销 |
| 完成 | 用户结束 | 按已拼内容输出长图 | 进入输出流程 |

已成功内容不回滚；「撤销最后一段」只删除最近一次成功追加并立即更新高度。

### Given/When/Then

| ID | Given | When | Then |
| --- | --- | --- | --- |
| GT-B82-8.1 | 静态可滚动页面 + 已选区域 | 指针在区域内持续向下滚动 | 无需点击「采集下一段」即连续拼接并实时预览（BRA82-05） |
| GT-B82-8.2 | 滚动到无连续内容/过快/横向偏移 | 触发任一异常 | 暂停并保留已拼内容；提供继续/撤销最后一段/结束 |
| GT-B82-8.3 | 已达高度/内存上限 | 继续滚动 | 停止追加并提示；已拼内容不丢失 |
