# BRA-113 PRD：录屏音频修复 + 录屏 UI 设计实现 + 打包

版本：v1.0
用户请求来源：BRA-113 父工单（用户 2026-08-16）+ 用户补充评论
交付对象：macOS 客户端（本地应用，无服务端任务）

## 1. 用户问题

1. **录屏音频**：现在无法在录屏时同时录制麦克风与扬声器（系统声音），甚至完全无法录制麦克风。
2. **录屏 UI 设计**：用户更新并补充了录屏 UI 设计，需检查设计文件与批注并实现设计内容。
3. **打包规则（长期约定）**：每次用户提出要求、处理完成后，都必须在项目文件夹内重新打包新版本，用新构建的 `ShotX.app` 覆盖项目根目录下的 `ShotX.app`。

**用户补充评论（关键 UI 要求）**：第一次录屏时，麦克风和摄像头应默认禁用；录屏的按钮（扬声器/麦克风/摄像头/鼠标）必须实现为**两种状态切换**（开/关），并且能够**正确指示功能开关的状态**（参考设计文件中「录制按钮禁用状态」画板）。

## 2. 范围

- 修复 `ScreenRecorder` 音频管线：支持同时录制麦克风 + 系统声音；麦克风必须真实可录。
- 按设计文件实现录屏 UI（`O-RSET` 录屏设置面板、`O-REC` 录制浮动条、录制按钮两态/禁用态）。
- 每次交付执行打包：构建新版本并替换项目根目录 `ShotX.app`。
- 首次录屏麦克风/摄像头默认关闭，按钮正确呈现禁用/关闭状态。

## 3. 非目标

- 不改动截图/滚动截图流程。
- 不引入账号、云端或网络服务。
- 不新增第三方依赖。
- 不做服务端任务（纯本地 macOS 应用）。

## 4. 用户流程

区域录屏 → 框选选区 → `O-RSET` 设置面板（扬声器/麦克风/摄像头/鼠标按钮 + 开始录制）→ 倒计时 → 录制（`O-REC` 浮动条）→ 停止 → 收尾/裁剪。

## 5. 关键状态

| 状态 | 说明 |
| --- | --- |
| `MIC-off` | 麦克风开关关闭：按钮显示关闭态，不请求权限，不采集 |
| `MIC-on` | 开关开启且权限已授予：开始采集；与系统声音同时写入 |
| `MIC-no-permission` | 权限不可用：按钮显示禁用/关闭态，提示文案 |
| 按钮两态 | 每个录制源按钮都有明确的「开/关」视觉状态，正确反映功能开关 |
| 首次录制 | 全新安装首次录屏，麦克风与摄像头默认关闭 |
