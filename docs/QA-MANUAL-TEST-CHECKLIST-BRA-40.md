## 2. 手测用例

> 每条用例为 Given（前置）/ When（操作）/ Then（期望）。结果填「通过 / 未通过 / 无法测试」，无法测试时说明原因。

### 2.1 摄像头移除（FR-REC-03）

- **TC-CAM-01**
  - Given：应用运行、已授权屏幕录制
  - When：触发区域录屏，进入录制设置菜单，并打开设置→录屏、设置→权限
  - Then：录制设置菜单、录屏设置页、权限页、菜单栏均不再出现任何摄像头开关、设备选择、预览、叠加或「摄像头」文案；无任何摄像头相关入口
  - 结果：

- **TC-CAM-02**
  - Given：首次启动 ShotX（或清除权限记录后）
  - When：开启麦克风录制，全程观察系统权限请求
  - Then：只弹出麦克风权限请求，绝不出现摄像头权限请求；输出 MP4 画面为纯屏幕内容，无摄像头画面叠加
  - 结果：

### 2.2 紧凑菜单（FR-REC-11）

- **TC-MENU-01**
  - Given：进入区域录屏，确认选区
  - When：观察弹出的录制设置菜单
  - Then：菜单明显比旧版更小更简洁，宽度约 300 pt；只包含「声音」「鼠标」「原始尺寸」「倒计时」四组，无摄像头、无分辨率下拉；「原始尺寸」为只读的 W × H px（物理像素）
  - 结果：

- **TC-MENU-02**
  - Given：录制设置菜单已打开
  - When：依次开启「麦克风」（展开设备列表）、切换「倒计时」关闭/3 秒、反复切换开关
  - Then：菜单正文区内部滚动/展开，底部「开始录制」主按钮始终完整可见、可点击，从不被挤出可视区
  - 结果：

- **TC-MENU-03**
  - Given：录制设置菜单已打开，未开始录制
  - When：移动选区、拖边/角调整选区尺寸
  - Then：选区与菜单同时可操作，原始尺寸随选区实时刷新；按 Esc 返回选区且不产生任何文件
  - 结果：

- **TC-MENU-04**
  - Given：录制设置菜单已打开，保持默认设置
  - When：直接按 Return 或点击「开始录制」
  - Then：不会因默认值自动跳过菜单直接录制；进入 3 秒倒计时后录制，输出 MP4 尺寸等于锁定选区的物理像素尺寸（无 1080p/720p 缩放）
  - 结果：
