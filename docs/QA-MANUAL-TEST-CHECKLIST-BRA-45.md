## 2. 手测用例

> 每条用例为 Given（前置）/ When（操作）/ Then（期望）。结果填「通过 / 未通过 / 无法测试」，无法测试时说明原因。

### 2.1 设置菜单打开后选区仍可操作（FR-REC-11）

- **TC-MENU-01**
  - Given：触发区域录屏（⌥⇧R），拖拽框选一个区域，回车确认，录制设置菜单已弹出
  - When：在菜单保持打开的状态下，用鼠标拖动选区内部
  - Then：选区随鼠标移动，无需点「返回选区」；菜单保持显示且可继续点击其中的开关
  - 结果：

- **TC-MENU-02**
  - Given：录制设置菜单已打开（同 TC-MENU-01 前置）
  - When：拖动选区四角/四边把手缩放选区
  - Then：选区可实时缩放，四角把手可点；拖动过程中菜单不被挤出可视区
  - 结果：

- **TC-MENU-03**
  - Given：录制设置菜单已打开，选区内有可辨识内容（如带文字的窗口）
  - When：先记下菜单「原始尺寸」的 `W × H px`，然后拖动选区一角扩大选区，再缩小回原始大小
  - Then：「原始尺寸」数值随缩放实时变化，与选区实际物理像素一致；选区复原后数值回到初始值（移动选区不改变数值）
  - 结果：

- **TC-MENU-04**
  - Given：录制设置菜单已打开
  - When：按 Esc
  - Then：菜单关闭，回到选区编辑态（把手仍可见）；不产生任何文件；可继续调整选区并按回车重新打开菜单
  - 结果：

- **TC-MENU-05**
  - Given：录制设置菜单已打开
  - When：点击「返回选区」
  - Then：菜单关闭，回到选区编辑态，选区与最近设置保留；可重新框选后再次进入菜单
  - 结果：

### 2.2 开始录制才锁定几何（FR-REC-12）

- **TC-LOCK-01**
  - Given：录制设置菜单已打开，且刚调整过选区尺寸
  - When：点击「开始录制」，观察倒计时与录制中的选区边界
  - Then：进入倒计时后把手消失，选区无法再移动/缩放；录制画面与菜单中最后一次显示的「原始尺寸」一致；视频轨分辨率等于该 `W × H px`，无缩放
  - 结果：

- **TC-LOCK-02**
  - Given：已进入倒计时（3 秒），尚未开始录制
  - When：按 Esc 取消倒计时
  - Then：返回录制设置菜单，选区与设置保持（仍是取消前锁定的几何）；可再次调整或开始
  - 结果：

### 2.3 回归抽查

- **TC-REG-01**
  - Given：区域录屏编辑态（已框选、未进菜单）
  - When：按空格键
  - Then：仍直接开始录制（跳过菜单），出现倒计时；Esc 取消不产生文件（快捷路径不受影响）
  - 结果：

- **TC-REG-02**

  - When：按 Esc
  - Then：取消选择层且不产生任何结果
