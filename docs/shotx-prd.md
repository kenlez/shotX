# ShotX macOS 截屏录屏软件 PRD

版本：v1.8（BRA-71 标注对象与录屏菜单修订）  
状态：可进入设计与开发  
日期：2026-08-13  
对应需求：BRA-25、BRA-35、BRA-36、BRA-41、BRA-52、BRA-71

## 1. 文档目的

定义一款在 macOS 上常驻运行、无需登录、以本地处理为默认的轻量截屏录屏工具。产品吸收 Xnip 在截图、标注、长截图和贴图上的高频能力，以及飞书桌面端录屏在区域选择、音视频源组合、快速裁剪和复制分享上的顺畅流程，但不复制飞书的 IM、会议和云协作体系。

## 1.1 BRA-71 变更单（本节优先于旧文中冲突表述）

### 用户问题与目标

现有马赛克和画笔交互不符合预期，部分标注未以可移动对象方式留在画布上，文字使用模态输入；录屏设置菜单在录制画面中不可见；系统分享功能不再需要。目标是让截图标注直接、可见且可重新定位，并让录屏启动前的菜单在选区中央可操作。

### 范围

| ID | 功能要求 | 验收标准 |
| --- | --- | --- |
| `FR-BRA71-01` | 马赛克改为矩形框选对象，不再接受画笔式连续轨迹。 | 拖拽产生一块矩形马赛克；可选择、拖动、删除、撤销/重做；导出后该矩形不可恢复底图。 |
| `FR-BRA71-02` | 画笔按鼠标路径绘制平滑自由路径（使用连续点与贝塞尔/等效平滑曲线），不再只产生起终点直线。 | 一次拖动形成随路径变化的连续笔迹；松开后可选择、拖动、删除、撤销/重做。 |
| `FR-BRA71-03` | 箭头、矩形、画笔、马赛克、文字等标注均作为画布对象就地呈现并可重新定位。 | 新建对象不弹出独立结果窗口；对象命中后可拖动；现有键盘删除、方向键移动与历史栈仍有效。 |
| `FR-BRA71-04` | 文字在选区内出现可编辑文本框；编辑完成后仍为可选择、可移动对象。 | 不使用 `NSAlert` 或其它模态文本输入；双击文字重入编辑；字体颜色、字号及 Figma 已提供的样式控件在画布内即时反映。 |
| `FR-BRA71-05` | 删除系统分享功能与相关 UI/代码/测试文案；复制、保存与贴图保留。 | 菜单、工具栏、结果窗口、文档和测试不再展示“分享”；无 `NSSharingServicePicker` 调用。 |
| `FR-BRA71-06` | 区域录屏的设置菜单放在当前框选区域中心，并在开始录制前可见可操作。 | 菜单中心随选区中心更新；不遮挡“开始录制”动作；开始录制后菜单从成片排除。 |

### 用户流程与关键状态

1. 区域截图后，用户在原选区内选择工具并直接绘制或插入文字；每次完成后对象保持可见且可再次选择、拖动或编辑。
2. 马赛克工具拖出矩形遮罩；画笔工具按指针轨迹生成平滑路径。
3. 区域录屏完成框选后，设置菜单锚定在选区中心；用户可调整选区或设置，菜单实时跟随，点击“开始录制”后才锁定选区并隐藏菜单。
4. 所有处理保持本地；系统分享不是替代流程，移除后只保留复制、保存和贴图。

### 非功能与非目标

- 继续使用现有 AppKit/Swift 标注模型和本地渲染路径，不新增第三方依赖或网络服务。
- 标注对象移动、编辑和导出不得倒置、镜像或破坏 Retina 物理像素映射。
- 本次不新增旋转、缩放、分组、图层面板、富文本段落样式或工程文件格式；“按 Figma 样式”限于现有设计资产与已定义的颜色/字号/粗细控件。

### 追踪与验证

`FR-BRA71-01…06` → UX 交互标注 → 客户端实现 → 单元/回归测试与独立 QA 手测清单。现有 `CAP-04/05/07/09/15/16`、`REC-11/12` 与本节共同适用；涉及系统分享的 `CAP-06/09` 等旧表述由 `FR-BRA71-05` 覆盖。

## 2. 用户问题

macOS 系统工具可以完成基础截图和录屏，但用户在以下任务中仍需切换多个应用或经历较长路径：

- 截图后立即标注、遮挡敏感信息、滚动拼接或置顶参考；
- 同时录制屏幕、系统声音和麦克风；
- 录制后只裁掉首尾，再快速复制或保存；
- 在包含敏感工作内容时，保证素材不被默认上传。

## 3. 产品定位与原则

### 3.1 一句话定位

ShotX 是面向知识工作者和开发者的本地优先 macOS 截屏录屏工具：快捷键唤起，完成后直接复制、保存或贴图。

### 3.2 产品原则

1. **快**：截图从唤起到可复制不超过一个主流程；录屏结束后直接进入轻量裁剪。
2. **简单**：菜单栏常驻，不建设内容管理后台，不强制用户创建项目。
3. **本地优先**：素材、编辑和导出默认只发生在本机；MVP 不提供账号或云上传。
4. **能力按场景出现**：截图展示标注工具，录屏展示音视频源，避免一个全功能编辑器承载所有操作。
5. **安全退出**：权限缺失、磁盘不足或设备断开时给出明确恢复路径，不静默丢失已录内容。

## 4. 目标、非目标与成功标准

### 4.1 MVP 目标

- 覆盖区域、窗口、全屏截图，以及手动滚动长截图；
- 提供截图标注、脱敏、复制、保存和贴图的闭环；
- 覆盖区域或单显示器录屏，并可组合系统声音、麦克风和鼠标效果；
- 提供录屏后首尾裁剪、复制和本地保存；
- 首次使用时完成 macOS 权限引导，并允许用户随时查看权限状态。

### 4.2 建议成功指标（Beta 阶段验证）

- 5 名目标用户中至少 4 名无需指导即可完成“区域截图并标注复制”和“带麦克风区域录屏并裁剪保存”；
- 已获权限时，区域选择层在快捷键触发后 300 ms 内可交互；
- 常见 1080p/30fps、30 分钟录屏成功导出率 ≥ 99%；
- Beta 会话无崩溃率 ≥ 99.5%；
- 不发生未获用户确认的网络上传。

指标均为产品目标，不代表当前已有实现或实测结果。

### 4.3 非目标

- 飞书会议录制、会议权限、参会人通知、妙记转写、评论和团队协作；
- 云空间、链接分享、账号体系、跨设备同步；
- 多轨时间线、转场、字幕、滤镜等专业视频编辑；
- 直播、推流、远程控制；
- Windows、iOS、Android；
- 自动识别并遮挡敏感信息。

| 竞品优势 | 竞品边界 | ShotX 取舍 |
| --- | --- | --- |
| Xnip 截图链路完整、长截图和贴图突出 | 公开定位仍以截图为主 | 保留截图优势，补齐一体化录屏 |

## 9. 用户流程

### 9.1 首次启动

1. 用户打开 ShotX，看到简短价值说明和“开始设置”。
2. 产品说明截图/录屏需要“屏幕与系统音频录制”权限；麦克风仅在用户启用对应来源时申请。
3. 用户完成授权；若系统要求重启 App，ShotX 保存当前步骤并在重启后继续。
4. 菜单栏显示就绪状态，用户可直接触发截图或录屏。

### 9.2 区域截图

1. 用户按截图快捷键。
2. 全屏出现半透明选择层，用户拖拽区域；边缘提供像素级放大镜和尺寸。
3. 松开后不结束截图、不打开独立结果窗口；继续停留在"选区高亮、周围变暗"的全屏选择层，并显示就地标注工具栏。
4. 在输出前，用户可随时移动选区、拖动边/角调整尺寸，并使用标注、马赛克、文字、撤销/重做和裁剪。选区内容按屏幕上的原可视尺寸 1:1 显示，不放大到独立编辑窗口；选区内画面方向与屏幕真实内容一致（不颠倒、不镜像），移动选区时选区内内容随选区同向移动。
5. 只有用户明确选择复制、保存、系统分享或贴图后才完成截图并退出选择层。
6. 默认主按钮执行上一次成功动作；Esc 随时无副作用退出。
7. 在选区内双击：直接把截图复制到剪贴板并退出选择层。
8. 框选完成（或编辑中）按空格：截图场景下直接把截图复制到剪贴板并退出；录屏选区场景下直接开始录制。

### 9.3 滚动截图

1. 用户选择“滚动截图”，框选只包含可滚动内容的区域。
2. ShotX 显示“开始”，并提示避免动画、横向偏移和过快滚动。
3. 用户向下滚动；侧边预览实时展示已拼接结果和当前状态。
4. 匹配失败时自动暂停，并说明原因；用户可继续、撤销最后一段或结束。
5. 结束后进入与普通截图相同的标注和输出流程。

### 9.4 区域录屏

1. 用户按录屏快捷键进入区域选择，拖拽并确认一个单显示器内的录制区域；也可切换为整个显示器。
2. 选区确认后、录制开始前，选区保持可见并弹出浮动设置菜单；不得跳过该菜单自动录制。
3. 菜单要小而简洁，只展示必要配置：声音（系统声音、麦克风独立开关及设备）、鼠标（指针、点击反馈独立开关）、只读的“原始尺寸 W × H px”和倒计时；不提供 1080p/720p 等缩放分辨率选项，不包含摄像头设置。菜单底部固定“开始录制”主按钮，任何配置展开或开关切换都不得把它挤出可视区。
4. 在点击“开始录制”前，用户可随时移动选区、拖动边/角调整尺寸，菜单保持可操作并实时更新原始像素尺寸。点击“开始录制”后立即锁定选区，倒计时和录制期间均不可再移动或缩放；设置菜单中的 Esc 返回选区且不开始录制。
5. 倒计时和录制期间，选区内部保持透明可见，选区外由四块纯黑遮罩覆盖；选区边缘显示高对比边框、角标和“录制区域”文字标识。标识不只依赖颜色，遮罩、边框、标签和状态条均不进入成片。
6. 状态条仅展示时长、声音状态和停止按钮；状态条不进入成片。
7. 用户停止后进入预览，可拖动首尾把手裁剪。
8. 用户复制或选择路径保存；保存完成后可在访达中显示。

### 11.1 MVP 冻结口径

- **快捷键（FR-BASE-02）**：保存前检查 ShotX 内部重复、macOS 已知保留组合及快捷键注册结果；无法可靠识别所有第三方占用。任一检查失败时拒绝保存、保留旧组合并提示重新输入。
- **设置持久化（FR-BASE-05）**：持久化窗口阴影、默认截图动作、各标注工具最近颜色/粗细、系统声音/麦克风/鼠标效果、倒计时、最近成功保存目录。改动从下一次捕获生效；“恢复默认”只重置这些配置，不修改系统权限、不删除素材或最近结果。
- **权限状态机（FR-BASE-03/04、FR-REC-02）**：屏幕、系统音频、麦克风分别呈现“未询问 / 已允许 / 已拒绝或受限”。屏幕权限缺失时阻止截图与录屏；其他来源缺失时自动关闭对应开关并允许无该来源继续。系统设置返回前台及 App 重启后立即重检；若系统要求重启，则恢复到原捕获模式入口，但不自动开始捕获。
- **多显示器选区（FR-CAP-01/03、FR-REC-01）**：MVP 的区域截图和区域录屏均限制在一个显示器内，不支持跨屏选区；选择层覆盖所有显示器，指针所在显示器为当前目标，拖拽到边界时截断。全屏截图和显示器录屏均为单显示器。
- **窗口与尺寸（FR-CAP-02/03）**：开启窗口阴影时，阴影计入预览与最终图片边界；关闭时均不计入。选区尺寸向用户显示最终导出的物理像素，内部可使用 point，但跨缩放换算不得改变输出像素口径。
- **标注工具（FR-CAP-04）**：箭头、矩形、画笔、文字、马赛克生成的对象均可选择、移动和删除；箭头/矩形/画笔支持颜色与粗细，文字支持颜色与字号，马赛克支持笔刷大小；裁剪不是标注对象。各工具只记忆自身最近样式。
- **截图就地编辑（FR-CAP-09）**：拖拽松开仅建立选区，不提交截图。输出前始终保持全屏选择层、选区高亮和外围暗化；工具栏与选区调整同时可用。选区内容在屏幕上按原 point 尺寸显示，Retina 只影响最终物理像素数，不得把截图放大到独立结果窗口。复制、保存、分享或贴图是提交动作；Esc 丢弃本次未提交内容。
- **区域截图方向与坐标（FR-CAP-10）**：选区内画面的 point 坐标系与屏幕实际方向一致；选区几何、冻结图像与捕获输出之间不得出现轴翻转或镜像，拖拽选区时画面随选区同向移动。
- **标注工具栏与取色器（FR-CAP-11/12）**：就地工具栏使用固定宽度与高度，颜色选择以浮层形式出现在工具栏下方，不改变工具栏尺寸、不挤占其他项。取色器必须能从选区对应的屏幕真实像素取色（覆盖层不得拦截取色命中），并以用户点击取色控件时鼠标位置作为左上角锚点出现，不固定于屏幕角落。
- **固定工具区与工具选项浮层（FR-CAP-14/15）**：工具栏本体（工具按钮与输出按钮行）在任何状态下长宽恒定、元素不增减。带选项的工具（颜色、粗细、字号、笔刷大小）的选项一律以 Dropdown Menu / Popover 浮层向下展开在工具栏正下方固定位置，浮层绝不改变工具栏尺寸、不挤占其它菜单项。切换工具只切换浮层内容，不回填工具栏行内。
- **可拖拽笔刷大小（FR-CAP-16）**：笔刷大小通过可拖拽组件（滑块/拖拽条）调整，拖动即时生效并记忆最近值；组件放在工具选项浮层内，默认展示当前记忆值。粗细离散档位与拖拽连续调整可并存，但以拖拽组件为默认交互入口。
- **区域截图快捷输出（FR-CAP-13）**：双击选区 = 复制截图到剪贴板并退出选择层；框选后按空格在截图场景 = 复制并退出、在录屏选区场景 = 直接开始录制。快捷动作只做单一输出，不弹出额外确认。
- **打开图片**：从 MVP 菜单删除“打开图片…”，不建设独立本地图片编辑入口；作为 P1 候选重新评估。
- **最近结果（FR-CAP-06/08、FR-REC-08）**：无结果时入口禁用；图片支持复制/保存/贴图；未保存视频支持复制/保存；已保存视频支持复制/另存/在访达显示。最近结果只保留到被新结果替换、明确丢弃或 App 退出，不跨重启持久化；清理前必须遵守未保存结果确认。
- **录制收尾（FR-REC-07/08/09）**：固定链路为“停止 → 收尾处理中 → 可播放预览 → 首尾裁剪 → 复制或保存”。处理中关闭或取消必须二次确认，并尽可能保留源临时文件；处理失败保留源文件。复制失败可重试或保存，保存失败可重试、另存或丢弃，任何失败都不得删除唯一可恢复副本。
- **长截图阈值（FR-LONG-01/02/03/04）**：以至少 20 个固定静态网页/文档样本验收，接缝或重复误差不超过 2 px，侧边预览在成功拼接后 500 ms 内更新。连续两帧无可靠重叠、横向偏移超过 8 px 或重叠低于 20% 时暂停。48,000 px 或 800 MB 时预警，60,000 px 或 1 GB 时停止追加并允许保存当前结果；阈值后续可由基准测试下调，不得无证据上调。
- **磁盘保护（FR-REC-09）**：开始录制前至少需要 2 GB 可用空间；低于 1 GB 时持续警告，低于 500 MB 时安全停止。恢复文件位于 App 容器的 `Application Support/ShotX/Recovery`；“可播放”指 MP4 已正确封装、具有非零时长且至少保留屏幕视频轨，存在音轨时仍满足第 13.2 节同步目标。
- **设备断开（FR-REC-10）**：麦克风或系统音频断开后，该轨从断开点起静音。其余轨道继续，立即提示受影响来源且不自动切换替代设备；剩余音视频同步目标仍小于 200 ms。
- **录制设置与确认（FR-REC-11）**：固定顺序为“选择录屏 → 框选区域并展示设置菜单 → 调整选区/设置 → 用户点击开始录制 → 锁定选区 → 倒计时 → 录制”。开始前菜单与选区必须同时可操作；声音按系统声音/麦克风分组并允许选设备，鼠标按指针/点击反馈分组。菜单为紧凑单列布局，尺寸控制到刚好容纳所需控件；“开始录制”固定在菜单底部最外层，任何分组展开、开关切换或选区调整都不把它挤出可视区。分辨率不是用户选项，只读展示当前选区的原始物理像素 `W × H`，选区变化时实时刷新。
- **录制区域显示（FR-REC-12）**：点击“开始录制”时锁定选区几何，倒计时和录制期间禁止移动或缩放。视频轨尺寸必须等于该选区的物理像素尺寸，不做 1080p/720p 缩放。录制时用四块非交互纯黑覆盖层形成透明选区孔，避免遮挡选区内部操作。选区边缘显示高对比实线、四角角标和“录制区域”文字，录制开始后同时显示 `REC` 文字/图标，不能只靠红色表达状态；所有覆盖层通过 ScreenCaptureKit 排除，不写入最终视频。

## 13. 非功能要求

### 13.1 兼容性

- MVP 支持 macOS 14 及以上；Apple Silicon 为首要验证平台，Intel Mac 纳入兼容性回归；
- 支持 Retina、多显示器、不同缩放比例和横竖屏混排；
- 使用 macOS 原生屏幕捕获、媒体编码、剪贴板和分享能力，避免新增账号或云依赖。

### 13.2 性能与稳定性

- 原始选区尺寸/30fps 为首发质量基线；30 分钟录制音画漂移目标小于 200 ms；
- 截图选择和标注过程中交互保持流畅，不因后台编码阻塞鼠标操作；
- 长截图和录屏使用有界缓存，临时数据持续落盘；
- App 异常退出后，下次启动可发现并恢复可用的未完成录屏，不自动删除唯一副本。

### 13.3 隐私与安全

- MVP 不包含登录、上传或远程配置；
- 权限说明必须写明采集内容和用途，拒绝后仍可使用不依赖该权限的能力；
- 临时文件仅存本机应用容器，导出或明确丢弃后按策略清理；
- 麦克风启用时始终有可见状态；
- 脱敏标注在导出时与图片合并，不保存可移除标注后显露原文的交付文件；
- 崩溃诊断如未来启用，必须单独征得同意且不得包含截图、录屏帧、文件名或 OCR 内容。

### 13.4 可访问性

- 菜单、设置和编辑工具提供 VoiceOver 标签；
- 关键动作可通过键盘完成；
- 状态不只依赖颜色表达；
- 倒计时和错误提示支持系统减少动态效果设置。

## 14. 数据与分析

MVP 不接入联网分析 SDK。为验证成功指标，内部 Beta 可在用户明确同意后记录不含内容的本地事件计数，例如捕获模式、成功/失败、耗时区间和错误码；用户可查看并导出诊断，也可一键清空。不得记录图像、视频、OCR 文本、窗口标题或文件路径。

## 15. 验收标准

MVP 只有同时满足以下条件才可进入发布候选（执行方标记：`后台`=团队后台自动验证，`手动`=用户手动验证；详见 `QA-ACCEPTANCE-MATRIX.md`）：

1. 在干净安装环境完成权限授予、拒绝后重试和系统设置返回三条路径（手动）；
2. 区域、窗口、全屏截图在 Retina 与双显示器场景下边界和尺寸正确（手动）；
3. 用户框选区域后不离开全屏选择层，可在原位置、原可视尺寸下持续调整选区并完成标注、不可逆马赛克、复制、保存、分享和贴图（后台+手动）；
4. 区域截图选区内画面方向与屏幕一致、不颠倒不镜像，拖拽选区时内容同向移动；标注工具栏固定尺寸且取色器不挤占其他项，取色器可对屏幕真实像素取色并以鼠标位置为左上角出现（后台+手动）；
4. 静态网页或文档可完成向下滚动拼接；错误滚动会暂停并可保存已成功部分（手动）；
5. 录屏设置阶段选区可随时移动/缩放，菜单展示声音、鼠标和实时原始像素尺寸；用户主动点击“开始录制”后选区立即锁定并进入倒计时，输出尺寸等于锁定时选区物理像素（后台+手动）；
6. 30 分钟原始选区尺寸/30fps 录屏可播放、可裁剪、可复制和另存（手动）；
7. 区域截图双击选区即复制到剪贴板并退出；截图场景按空格复制并退出，录屏选区场景按空格直接开始录制（后台+手动）；
8. 录制时输入设备断开、磁盘空间不足、导出失败均不会静默丢失唯一可恢复素材（手动）；
9. 倒计时和录制期间，选区外显示纯黑遮罩，选区由边框、角标和文字持续标识；ShotX 自身选择层、遮罩、标识和控制条均不进入最终截图/录屏（手动）；
10. 所有内容处理默认在本地完成，网络断开不影响 P0 主流程（后台）；
11. 目标用户可用性测试达到第 4.2 节门槛，且所有 P0 缺陷已关闭或有明确发布阻断结论（手动）。
12. 标注工具栏工具区尺寸与元素在任意工具/状态下恒定，工具选项以浮层向下展开在工具栏下方、可拖拽笔刷大小组件调整笔刷并记忆（后台+手动，覆盖 FR-CAP-14/15/16）。

## 17. 风险与待验证项

| 风险/假设 | 影响 | 验证方式 |
| --- | --- | --- |
| 长截图对动态内容和复杂背景不稳定 | 可能降低核心能力成功率 | 用网页、聊天、代码、表格建立至少 20 个样本的拼接基准 |
| 不同 App 对“复制视频”支持不一致 | 用户可能误以为复制失败 | 验证 Finder、邮件、常见 IM 和文档；不支持时回退为复制文件引用并提示 |
| 系统音频与麦克风混录存在回声或漂移 | 成片质量受损 | 对不同输出设备做 5/30/60 分钟基准测试 |
| Retina 大选区的原始尺寸可能增加编码负载和文件体积 | 可能影响长录制稳定性 | 用 1/4 屏、1080p、Retina 全屏三档做 5/30 分钟基准；不得以静默缩放替代失败提示 |
| macOS 权限重启路径可能造成流失 | 首次任务无法立即完成 | 首次体验可用性测试并记录每一步完成率 |
| 紧凑菜单在展开设备选择等列表时是否挤掉“开始录制” | 用户无法开始录制 | 交互稿与实现均固定“开始录制”于菜单最外层并做回归验证 |

## 18. 研发与 QA 交付边界

### 18.1 测试与交付模型（BRA-35 修订，替代先前桌面操控测试方式）

自 BRA-35 起，团队**不再在用户电脑上进行需要操控桌面的测试**（不远程控制、不自动操控用户机器桌面执行用例）。

- **需要用户实测的功能**：一律以“构建产物/安装包附件 + 用户手动验证”交付。团队产出可安装的包体（如 `ShotX.app.zip`、源码包）作为附件提供，附上手测清单（步骤、期望结果），由用户自行安装验证并反馈。
- **团队侧只保留不依赖电脑操控的后台测试闭环**：自动化单元/逻辑测试、静默构建与签名校验、静态检查等无需操控桌面即可后台运行的验证。凡是依赖真实硬件/桌面的用例（权限弹窗、多显示器、设备热插拔、真实录制等），不再由团队在用户机器上执行，改为包体交付后由用户实测。

### 18.2 阶段推进

建议实现按真实依赖分三阶段推进：

1. **阶段 1：捕获底座**——权限、菜单栏、快捷键、屏幕/窗口枚举、区域选择、文件与剪贴板输出；
2. **阶段 2：并行能力**——截图标注/贴图/长截图，以及 MP4 录制/音视频源/控制状态；
3. **阶段 3：统一收口**——录屏裁剪、异常恢复、多显示器回归、性能与隐私验收。

设计需先交付选择层、截图工具栏、录屏设置条、录制状态条和权限页的关键状态；客户端以本地能力实现，MVP 不创建服务端；QA 依据第 15 节独立建立验收矩阵，并覆盖权限、磁盘、设备断开和多显示器异常路径。凡验收标准中依赖真实桌面/硬件的条目，按 18.1 改为包体交付 + 用户手动验证；QA 团队侧只执行可后台运行的自动化验证。
