## BRA-82：截图与录屏交互修复

### 用户问题

截图贴图方向错误、对象与选区拖动不稳定，工具栏与录屏菜单偏离最新设计；滚动截图仍需手动逐段采集，扩展显示器与被外部删除的视频会阻断主流程。

### 范围与用户流程

1. 区域截图可在任一已连接显示器开始；在同一显示器内框选、标注和输出。跨显示器拖拽不是本次范围。
2. 截图在原选区内编辑。矩形、椭圆、画笔、箭头、马赛克、文字均为可选中对象；选中后可拖动、Delete 删除、方向键微调、撤销/重做。
3. 截图工具栏移除独立移动工具，按核对后的设计图使用 SVG 工具图标、分割线和工具专属的样式下拉面板；长截图保留独立动作，绝不冒充矩形工具。
4. 贴图输出保持图像方向，拖动时位置连续稳定；不引入图像编辑器重构。
5. 区域录屏的设置态与录制中控制条按最新设计图使用导出的 SVG 资产；设置/覆盖 UI 不进入成片。
6. 滚动截图在选区内监听用户滚轮：滚动后自动连续捕获、按重叠区域拼接并实时预览；无连续内容、横向偏移、过快或到上限时暂停，保留已拼内容，可结束或撤销。
7. 视频预览的源文件被访达删除、移走或不可读时，窗口仍可关闭，App 可退出，并提示恢复路径；不得死锁或无限等待。

### 功能要求与验收

| ID | 要求 | Given / When / Then |
| --- | --- | --- |
| BRA82-01 | 贴图图像与最终截图方向一致。 | Given 非对称测试图，When 贴图，Then 不上下/左右颠倒。 |
| BRA82-02 | 标注对象可选择、移动和删除。 | Given 任一已完成矩形/椭圆/画笔对象，When 选择并拖动或按 Delete，Then 仅该对象移动或删除，撤销可恢复。 |
| BRA82-03 | 工具栏与样式浮层严格采用设计核对产物。 | Given 截图编辑态，When 切换任意工具，Then 无移动图标；矩形、椭圆、长截图入口语义正确；SVG、分割线与 `drop_over_normal`（文字专属变体除外）一致。 |
| BRA82-04 | 录屏菜单、录制中菜单使用核对后导出的 SVG。 | Given 区域录屏，When 设置/开始/停止，Then 元素、层级和状态与设计图一致，且不进入成片。 |
| BRA82-05 | 滚动截图自动连续采集。 | Given 静态可滚动页面和已选择区域，When 指针在区域内持续向下滚动，Then 无需“采集下一段”按钮即可连续拼接并实时预览。 |
| BRA82-06 | 贴图拖动不跳帧。 | Given 已贴图，When 连续拖动，Then 窗口跟随鼠标且无坐标跳变/闪烁。 |
| BRA82-07 | 扩展屏幕可用。 | Given 至少两个显示器，When 指针移入扩展屏幕后启动区域截图，Then 该屏幕的选择层接收鼠标并可完成单屏截图。 |
| BRA82-08 | 视频预览对外部删除安全。 | Given 录屏预览打开，When 在访达删除源文件后尝试关闭窗口或退出，Then App 不阻塞，窗口可关闭并显示可理解的错误。 |

### 非功能、边界与验证

- 仅使用现有 AppKit、CoreGraphics、ScreenCaptureKit 和系统 API；不新增网络服务或第三方依赖。
- Retina 与异构缩放显示器中必须按各自屏幕坐标/像素比例映射；多屏同时合并为一张图不在本次范围。
- 自动滚动不模拟鼠标滚轮、不控制第三方 App；仅消费用户在选区内真实滚动事件并自动采样。动态内容无法可靠匹配时须暂停而非输出错误拼接。
- 所有非平凡逻辑需留最小可运行自动化检查；真实多屏、滚动页面、录制权限和访达删除场景在 macOS 桌面按手测清单验证。
