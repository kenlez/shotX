## 主要迭代阶段小结

### 阶段 1：立项与基础底座（BRA-25…BRA-28，2026-08-04 起）
- 调研 Xnip 与飞书录屏，产出 macOS 截屏录屏软件 PRD；ShotX MVP UX/UI 设计；macOS 捕获底座；本地 MVP 客户端实现。

### 阶段 2：截图/录屏交互收敛（BRA-30…BRA-48，2026-08-12~13）
- 录屏选区锁定与原始尺寸输出、截图提交前就地选区编辑；录屏菜单精简紧凑、移除摄像头；区域截图标注修复（方向翻转、固定工具栏、取色器、双击/空格输出）；贴图窗口移动/缩放/关闭修复。

### 阶段 3：标注工具栏重构与可访问性（BRA-52…BRA-68，2026-08-12~13）
- 固定工具区、工具选项下拉/弹出层、可拖拽笔刷大小（FR-CAP-14/15/16）；完整键盘焦点链与 VoiceOver 公告；窄屏响应式；整合为 0.1.2 发布。

### 阶段 4：Figma UI 落地与贴图优化（BRA-70…BRA-100，2026-08-13~16）
- 应用 ShotX Figma 设计/图标/批注；改进标注工具与录屏菜单、移除分享；修复截图闪退（Bundle.module）；pin 图 UI 严格按设计稿 8 条批注优化（实时数字回显、滑动槽样式、100% 吸附、hover 渐显）；补齐 Cmd+W 关闭 / Esc 隐藏。

### 阶段 5：滚动截屏与长图修复（BRA-88…BRA-92，2026-08-15）
- 修复 0.1.12 滚动截屏「有高度但内容重复」：重叠匹配/裁剪拼接产生重复段 → 重叠段去重，长图拼接连续。QA 固化复现 + 独立复测闭环。

### 阶段 6：录屏体验与权限体系（BRA-102…BRA-124，2026-08-16~17）
- 权限弹窗置顶、首次录屏默认禁用摄像头/麦克风、摄像头画中画；Alimama 字体替换并打入包体；录屏音频（系统声+麦克风）根因修复并实现最新录屏 UI；首次权限申请真实触发（TCC 注册）。

### 阶段 7：识别与稳定性（BRA-126…BRA-143，2026-08-17）
- 窗口截图识别修复（被遮挡窗口剔除、z-order 层级优先）；录屏 UI 颜色蓝口径核对；持续拖动矩形框崩溃修复（多轮守卫补全）；按用户长期打包规则持续出新包。
