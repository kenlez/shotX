# ShotX QA 验收矩阵（BRA-35/37 修订版）

对应 PRD v1.7（shotx-prd.md）需求追踪与 §15 验收标准。自 BRA-35 起团队不再操控用户桌面执行测试，所有验收条目只存在两种执行方：

- **团队后台自动验证**：不依赖真实桌面/硬件，可在后台静默运行（单元/逻辑测试、静态检查、静默构建与签名校验）。
- **用户手动验证**：依赖真实桌面/硬件（权限弹窗、摄像头、多显示器、设备热插拔、真实录制/拼接等），随包体附件交付用户自行验证。

执行方为「团队后台＋用户手动」的条目，其可后台验证的逻辑部分由团队完成，桌面交互部分仍须用户实测，二者都不省略。

## 1. 团队后台测试闭环（可静默运行）

| 检查 | 命令 | 说明 | 本次证据 |
| --- | --- | --- | --- |

| 静态检查（无网络） | 检索源码网络 API 调用 | MVP 本地优先承诺 | 无 `URLSession` 等网络代码 |
