# ShotX 功能缺口审计（2026-08-15）

## 本次已完成

- 菜单栏截图收敛为唯一「截图」入口，快捷键设置也不再暴露旧的窗口、全屏、滚动截图独立入口。
- 未拖动时，鼠标移过窗口会实时用蓝框高亮；没有命中窗口时默认整屏。单击接受当前蓝框，拖动则创建区域。
- 窗口和全屏结果不直接结束，会留在原地进入同一套标注工具栏。滚动截图仍只在区域成立后出现。
- 滚动拼接现在会排除固定侧边栏、固定顶栏和固定底栏，一次滚动超过半屏时停止猜测，重复列表存在多个近似匹配时也会拒绝错误拼接。
- 滚动预览左上角实时显示当前输出物理像素尺寸。

## 确认没做到或做错的功能

### P0：应继续修复

1. **滚动截图还没有真实桌面验收。** 当前是根据滚轮事件每 140 ms 请求一帧并做像素匹配，不是 macOS 原生长截图 API。动态广告、视频、虚拟列表、大面积重复纹理和过快滚动仍可能暂停；需用真实 Finder、浏览器、代码编辑器样本验收。
2. **滚动截图的暂停原因对普通用户不可见。** 当前只写入了辅助功能值，预览上没有可见的「匹配失败 / 滚动过快 / 到达上限」状态文字。
3. **「窗口截图保留阴影」设置现在无效。** 统一截图使用冻结整屏图像中的窗口矩形，没有走独立窗口阴影捕获。设置页不应继续暗示该开关已生效。
4. **系统声和麦克风同时开启时没有混成单一音轨。** 当前 MP4 中写入两条独立音轨，不同播放器可能只选择其中一条，不能保证用户听到两者。
5. **录屏按钮没有真正的「禁用态」。** 资产只被当作 on/off 切换；权限不可用或设备不存在时，按钮仍可点，只在开始录制时回退为关闭。
6. **多显示器、录屏声画和摄像头叠加只有逻辑测试，没有真机验收证据。** 坐标换算和输出尺寸有自动测试，但外接屏垂直排列、不同缩放比、声画同步、摄像头方向仍需真机检查。

### P1：实现不完整或设计仍未闭环

1. **Dropover 和主工具栏只验证了行为，没有像素级视觉回归。** 常驻、跟随工具、0.2 s 消失和 SVG tail 已有测试；颜色、间距、圆角、阴影和尾巴衔接仍需用 Figma 对比图验收。
2. **滚动截图没有「撤销上一段 / 手动暂停」。** 现在只有取消、贴图、保存和复制。
3. **视频预览没有裁剪能力。** 应用使用 AVPlayer 自带控件并已移除多余的首尾条；如果产品仍要求「只剪去开头和结尾」，这一项尚未实现。
4. **录屏设置中保留了一批未使用的旧 SwiftUI 组件。** 它们不会显示，但会让以后修样式时误改旧界面。
5. **旧的独立截图结果窗口代码仍存在。** 新的统一截图入口不再使用它，但内部旧模式还可调到这条路径，后续应删除或彻底收敛。
6. **产品 / QA 文档已与代码冲突。** 旧验收矩阵仍写着「摄像头功能已移除」和「截图有多个独立模式」，而当前代码已相反；不能再直接用旧矩阵判定功能完成度。

## 建议的下一步顺序

1. 用 3 类真实滚动样本完成长截图验收，保留失败前后的原始帧作为回归样本。
2. 把系统声和麦克风混成单音轨，并补权限 / 设备禁用态。
3. 决定窗口阴影在「原地标注」中的产品规则，然后实现或删除无效开关。
4. 用最新 Figma 截图建立 Dropover、截图工具栏、录屏菜单和 Pin 图的视觉回归图。
